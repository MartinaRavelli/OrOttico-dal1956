# OrOttico — Progetto didattico

Questo sito è stato realizzato interamente da me come **esercizio scolastico** per un esame di sviluppo web (HTML, CSS, JavaScript, con l'aggiunta di GSAP e Tailwind).

Il contenuto testuale è ispirato a un'attività commerciale realmente esistente, usata come riferimento visivo e stilistico per l'esercizio. **Questo progetto non è affiliato, autorizzato o gestito dal negozio reale**, ed è pubblicato esclusivamente a scopo didattico.

## Tecnologie usate
- HTML5 semantico
- CSS3 (Flexbox, Grid, media query)
- JavaScript vanilla (DOM, eventi, validazione form)
- GSAP + ScrollTrigger (animazioni)
- Tailwind CSS (elemento singolo)
